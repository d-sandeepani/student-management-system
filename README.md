# Student Registration System

A beginner-level Student Registration System developed using PHP and MySQL.

## Features

- Add students
- View students
- Edit student information
- Delete students
- Search students
- Dashboard statistics
- Server-side validation
- MySQL database integration
- Responsive user interface

## Technologies

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP
Database

Database name:

student_registration

Table:

students

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project into the XAMPP htdocs folder.
4. Create the student_registration database.
5. Create the students table.
6. Open the project using localhost.
