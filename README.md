# Student Registration System

A beginner-level Student Registration System developed using PHP and MySQL.

## Features

- Add students
- View students
- Edit student information
- Delete students
- Search students
- Dashboard statistics
- Server-side validation
- MySQL database integration
- Responsive user interface

## Technologies

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP
